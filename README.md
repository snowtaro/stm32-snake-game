# STM32 Snake Game
> 2025년도 2학기 임베디드시스템 설계 및 실험 수업 텀프로젝트입니다. <br>
> STM32 마이크로컨트롤러를 이용해 임베디드 환경에서 직접 구현한 디스플레이와 조이스틱을 활용한 클래식 스네이크 게임입니다.

<br>

## 프로젝트 개요
STM32F10x MCU를 기반으로 개발된 스네이크 게임(Snake Game) 프로젝트입니다. 조이스틱을 통해 뱀을 조작하고 LCD에 게임 화면을 출력하며, 센서를 활용한 부가 기능(다크 모드, 절전 모드 등)과 블루투스 통신, 사운드 출력 기능이 포함되어 있습니다.

<br>

## 주요 기능 (Features)
- **클래식 스네이크 게임**: 벽이나 자기 몸에 부딪히면 게임 오버, 먹이(`*`)를 먹으면 뱀의 길이와 점수가 증가합니다.
- **조이스틱 제어**: 4방향(상, 하, 좌, 우)으로 뱀의 이동 방향을 조작합니다.
- **LCD 디스플레이**: 자체 렌더링 시스템을 통해 게임 화면(머리 `O`, 몸통 `o`, 먹이 `*`)을 출력합니다.
- **절전 모드 (PIR 센서)**: 10초 동안 사람의 움직임이 감지되지 않으면 LCD를 절전 상태로 전환하여 전력을 절약합니다.
- **자동 다크 모드/라이트 모드 (CDS 센서)**: 주변 밝기를 감지하여 인터럽트 발생 시 LCD 배경색과 오브젝트 색상(흑/백)을 실시간 반전합니다.
- **게임 사운드**: 먹이 획득 시, 게임 오버 시 부저(Buzzer) 사운드 효과가 발생합니다.
- **게임 통계 전송 (DS1302 RTC & Bluetooth)**: 게임 플레이 시간을 초 단위로 측정하며, 게임 종료 후 블루투스를 통해 점수 및 플레이 시간 등의 결과를 외부로 전송합니다 (게임 중에는 진행 유지를 위한 Heartbeat 전송).

<br>

## 하드웨어 구성 (Hardware Configuration)
- **MCU**: STM32F10x 계열
- **입력**: 조이스틱
  - PC4: 상 (UP)
  - PB10: 하 (DOWN)
  - PC13: 좌 (LEFT)
  - PA0: 우 (RIGHT)
- **출력**: TFT LCD 디스플레이, 부저/스피커 (Sound 처리용)
- **센서**: 
  - 조도 센서 (CDS) - 다크 모드 전환용
  - 인체 감지 센서 (PIR) - 절전 모드 동작용
- **모듈**: 블루투스 모듈 (Heartbeat 및 스코어 송신용), DS1302 RTC 모듈 (게임 진행 시간 측정)

<br>

## 소프트웨어 구조 (Software Structure)
- `main.c`: 게임 주 루프, 센서 폴링 메커니즘 관리, 게임 오버 및 이벤트 상태 관리
- `snake.c`: 뱀 이동, 음식 생성, 충돌 로직 검사 및 점수 계산 처리를 담당하는 핵심 게임 엔진
- `display.c`: LCD 렌더링, 오브젝트 출력 및 절전 모드, 다크/라이트 모드 시의 디스플레이 색상 제어
- `joystick.c`: GPIO 입력을 통한 조이스틱 방향 매핑
- 여러 외부 장치 제어 모듈: `sound.c`(사운드), `ds1302.c`(RTC 시간 관리), `pir.c`(인체 감지), `cds.c`(빛 감지), `bt.c`(블루투스 UART 통신)

<br>
